# 合鸣跨端通信协议

## 概述

合鸣桌面端与移动端通过局域网直接通信，**无需云服务器中介**。

### 技术栈
- **设备发现**: mDNS/Bonjour（自动发现同网段设备）
- **实时通信**: WebSocket（双向实时数据流）
- **数据同步**: REST API（请求-响应式调用）

## 连接流程

```
┌─────────┐                    ┌─────────┐
│  手机端  │                    │  电脑端  │
└────┬────┘                    └────┬────┘
     │                              │
     │  1. mDNS 广播/发现           │
     │◄────────────────────────────►│
     │                              │
     │  2. WebSocket 连接           │
     │─────────────────────────────►│
     │                              │
     │  3. 设备信息交换              │
     │◄────────────────────────────►│
     │                              │
     │  4. 状态同步                  │
     │◄────────────────────────────►│
     │                              │
     │  5. 实时通信                  │
     │◄────────────────────────────►│
```

## 消息格式

所有消息采用 JSON 格式，包含以下字段：

```typescript
interface Message {
  id: string;        // 消息唯一 ID
  type: string;      // 消息类型
  from: string;      // 发送者设备 ID
  to: string | null; // 目标设备 ID（null = 广播）
  ts: number;        // 时间戳
  payload: unknown;  // 消息内容
}
```

## 消息类型

### 设备管理
- `device:online` — 设备上线通知
- `device:offline` — 设备离线通知
- `device:list` — 请求设备列表
- `device:list:response` — 设备列表响应

### 任务管理
- `task:create` — 创建任务（手机 → 电脑）
- `task:create:response` — 任务创建响应
- `task:status` — 任务状态更新（电脑 → 手机）
- `task:cancel` — 取消任务

### Agent 事件
- `agent:event` — Agent 实时事件流

### 聊天
- `chat:send` — 发送聊天消息
- `chat:message` — 聊天消息广播

### 远程控制
- `control:command` — 远程控制命令
- `control:response` — 控制命令响应

### 状态同步
- `sync:request` — 请求状态同步
- `sync:response` — 状态同步响应

### 心跳
- `ping` — 心跳请求
- `pong` — 心跳响应

## 安全机制

1. **设备配对** — 首次连接需确认配对
2. **消息签名** — 关键消息需签名验证
3. **权限控制** — 不同设备类型有不同权限
4. **超时断开** — 心跳超时自动断开

## 错误处理

- 连接断开自动重连（指数退避）
- 消息发送失败自动重试（最多 3 次）
- 状态不一致时触发全量同步

## 扩展点

1. **自定义消息类型** — 通过 `type` 字段扩展
2. **插件系统** — 消息处理中间件
3. **端到端加密** — 可选的消息加密层
